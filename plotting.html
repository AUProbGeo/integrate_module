Plotting profiles¶

Overview¶

ig.plot_profile draws a 2-D cross-section (a profile) through a set of 1D posterior results stored in a posterior HDF5 file. Each column of the section is one sounding; the vertical axis is elevation, obtained from the layer depths in the prior file and the surface elevation in the data file.

The function inspects the prior file and dispatches automatically:

  • continuous model parameters (e.g. resistivity) → ig.plot_profile_continuous()

  • discrete model parameters (e.g. lithology classes) → ig.plot_profile_discrete()

All options below can be given to plot_profile and are forwarded to the right function. The worked example Profile Visualization in INTEGRATE shows every option on the DAUGAARD case.

Minimal use:

import integrate as ig

# All models, all soundings, default panels
ig.plot_profile(f_post_h5)

# Model 1 only, soundings 1-500
ig.plot_profile(f_post_h5, im=1, i1=1, i2=500)

If the posterior file does not yet contain posterior statistics (/M1/Mean, /M1/Mode, …), plot_profile computes them first by calling ig.integrate_posterior_stats().

Selecting soundings and the horizontal axis¶

Which soundings appear, and in what order, is controlled by three arguments:

im

Model parameter to plot: 1 for /M1, 2 for /M2, … im=0 (the default) plots every model in turn.

ii or i1/i2

ii is an explicit array of (0-based) sounding indices, typically the soundings of one flight line. i1/i2 give a 1-based range and are used only when ii is not given.

xaxis

'index' (default) – sequential position along the profile; 'id' – sounding index in the file; 'x' / 'y' – UTM coordinate. With 'x'/'y' the soundings are sorted along that coordinate.

gap_threshold

Where consecutive soundings are farther apart than this (in the units of xaxis) the section is left blank instead of being stretched across the gap. Useful with xaxis='x' or 'y'.

A typical call for one line:

X, Y, LINE, ELEVATION = ig.get_geometry(f_data_h5)
id_line = np.where(LINE == 100)[0]

ig.plot_profile(f_post_h5, im=1, ii=id_line, xaxis='x', gap_threshold=50)

Panels¶

The figure has three stacked panels, chosen with panels=[...]. When a panel is left out its space is kept, so figures with different panel sets line up.

Panel

Continuous model

Discrete model

first

'value' – HarmonicMean by default; 'median', 'mean' or 'harmonicmean' select the statistic; 'realization' – see below

'mode' – most probable class; 'realization' – see below

second

'std' – log10 standard deviation (plot_kl=True shows KL divergence instead, if stored)

'entropy' (plot_kl=True shows KL divergence instead, if stored)

third

'stats' – annealing temperature and reduced χ² (show_n_unique=True adds the number of unique realizations)

same

Examples:

ig.plot_profile(f_post_h5, im=1, panels=['value'])
ig.plot_profile(f_post_h5, im=1, panels=['median', 'stats'])
ig.plot_profile(f_post_h5, im=2, panels=['mode', 'entropy'])

Uncertainty transparency¶

alpha (0–1) fades the first panel where the posterior is uncertain: driven by the standard deviation for continuous models and by the entropy for discrete models. alpha=0 (default) is fully opaque; alpha=1 gives the strongest fade. The range mapped to transparent is set with logstd_min/logstd_max (or std_min/std_max) for continuous models and entropy_min/entropy_max for discrete models:

ig.plot_profile(f_post_h5, im=1, alpha=0.8, logstd_min=0.3, logstd_max=0.8)
ig.plot_profile(f_post_h5, im=2, alpha=1.0, entropy_min=0.5, entropy_max=0.6)

Prior and posterior realizations¶

The panels above show statistics of the posterior. Statistics are smooth by construction and do not show what a single model consistent with the data looks like. panels=['realization'] replaces the first panel with one realization per location instead.

How it works¶

The posterior file stores /i_use with shape (n_soundings, n_real): for every sounding, the indices of the prior models that were accepted as posterior samples. For each location in the profile one random entry of /i_use is drawn and the corresponding model from the prior file (/M{im}) is plotted. Columns are independent draws – neighbouring soundings are not made consistent with each other – which is what a realization-based section should show.

seed makes the draw reproducible; the other panels (std/entropy, stats) are unchanged and still show the posterior statistics:

# One posterior realization per location, with std and stats
ig.plot_profile(f_post_h5, im=1, ii=id_line, xaxis='x', gap_threshold=50,
                panels=['realization', 'std', 'stats'], seed=1)

# Discrete model
ig.plot_profile(f_post_h5, im=2, ii=id_line, xaxis='x', gap_threshold=50,
                panels=['realization'], seed=1)

alpha works on the realization panel too, fading cells where the posterior std / entropy is high.

Prior realizations¶

plot_prior=True replaces /i_use with random prior indices of the same shape before the draw, so the panel shows a prior realization per location. Plotting a prior and a posterior section with the same seed is a direct visual check of how much the data have constrained the model:

ig.plot_profile(f_post_h5, im=1, ii=id_line, xaxis='x', gap_threshold=50,
                panels=['realization'], plot_prior=True, seed=1,
                title='Prior realization')
ig.plot_profile(f_post_h5, im=1, ii=id_line, xaxis='x', gap_threshold=50,
                panels=['realization'], seed=1,
                title='Posterior realization')

Choosing the realizations yourself¶

i_plot_realization bypasses the random draw. It must be an array of prior indices with one entry per location, either of length len(ii) (the locations in the profile) or of length n_soundings (all locations; it is then subset by ii). A scalar is rejected, since one prior model at every location is not a meaningful section.

The most common use is a fixed column of /i_use – “posterior realization number k at every location”:

with h5py.File(f_post_h5, 'r') as f_post:
    i_use = f_post['/i_use'][:]

ig.plot_profile(f_post_h5, im=1, ii=id_line, xaxis='x',
                panels=['realization'], i_plot_realization=i_use[:, 5])

Any other selection works the same way, for example prior indices drawn in your own script, or one index per location picked by some criterion:

with h5py.File(f_prior_h5, 'r') as f_prior:
    N = f_prior['/M1'].shape[0]
i_prior = np.random.default_rng(1).integers(0, N, size=len(id_line))

ig.plot_profile(f_post_h5, im=1, ii=id_line, xaxis='x',
                panels=['realization'], i_plot_realization=i_prior)

Titles and saving to file¶

title adds a figure title above all panels. fontsize sets the size of all text.

hardcopy=True writes a PNG file. The name is generated from the posterior file name, the index range, the model and the panels; txt appends a suffix to it. f_png sets the file name explicitly instead (give a specific im with it – im=0 would write every model to the same file):

ig.plot_profile(f_post_h5, im=1, ii=id_line, xaxis='x',
                title='Line 100 – resistivity', hardcopy=True)

ig.plot_profile(f_post_h5, im=1, ii=id_line, xaxis='x',
                panels=['realization'], seed=1,
                hardcopy=True, f_png='line100_M1_realization.png')

Borehole overlay¶

BHOLES draws borehole logs on the model panel (mode or realization for a discrete model; value or realization for a continuous model). It accepts the same input as ig.plot_boreholes(): a borehole dict, a list of dicts (e.g. from ig.read_borehole()) or a JSON file name.

Each borehole is drawn as a column at the profile location nearest to it. Boreholes further than bhole_max_dist (default 200 m) from every plotted location are skipped. The column hangs from the borehole elevation, or from the elevation of the nearest sounding if the borehole has no valid elevation (missing, 0 or -9999). The colors are the class colors of a discrete prior model, as in ig.plot_boreholes(): the plotted model for a discrete profile, or the first discrete model in the prior for a continuous profile. bhole_im selects another model.

bhole_width sets the column width in pixels (default 10). bhole_label (default True) writes the borehole name above each column. bhole_alpha=True sets the opacity of each interval to its class_prob:

BHOLES = ig.read_borehole('boreholes.json')
ig.plot_profile(f_post_h5, im=2, ii=id_line, xaxis='x',
                BHOLES=BHOLES, bhole_max_dist=150, bhole_width=12)

# resistivity profile, boreholes colored by the lithology model M2
ig.plot_profile(f_post_h5, im=1, ii=id_line, xaxis='x',
                BHOLES=BHOLES, bhole_im=2)
